EC2 Deployment Ready (Zero Key Management)

When deploying to an EC2 instance, attach an IAM Role with AmazonDynamoDBFullAccess (or custom policy for StudentRecords). The AWS SDK v3 automatically fetches temporary STS credentials via the EC2 Instance Metadata Service (IMDS).

Health Check & Monitoring

The route GET /health returns {"status":"ok","uptime":process.uptime()}. This is configured for CloudWatch Synthetics, AWS ALB Health Checks, and Auto Scaling group health checks.
